# 芒语词汇注释表

> **资料类型：** 简明词典
> **适用时机：** 练习讲述时快速查阅芒语专有词汇
> **来源：** 合编本《附录 A.1》

---

| 词汇 / 术语 | 释义 |
|---|---|
| **Mo lêu / Mo tiêu** | 按时间顺序吟唱天地、族群与 Lang 家族历史的史诗莫礼（即《生土生水》），区别于引导亡灵升天的神灵吟诵 *Mo vải*。 |
| **Rằng** | 莫礼吟诵中的章、段；每段结束时，莫师常拖腔转调并轻摇铜铃换气。 |
| **Ông mo / Âu mo** | 掌管史诗记忆与丧礼仪式的莫师（祭司）；*Âu mo* 指行祭占卜的男性祭司。 |
| **Ông mơ** | 第 18 章中代 Lang 家提亲的媒人，不同于祭司 *Ông mo*。 |
| **Chu chương** | Lang 家治理下的村寨百姓与共同体（常连称 *chu chương mường nước*）。 |
| **Cun / Lang / Đạo** | 古芒族社会中的头领与世袭爵位（*Lang Cun* 居首，下有 *Đạo*、*Chấu*、*Vá* 分掌军政）。 |
| **Mường Mọn** | 芒族古老的自称。 |
| **Khâu lạc** | 神圣的铜鼓——象征 Lang 家族权威的重宝（第 19 章）。 |
| **Khót（Khót chu, khót lụi）** | 具有灵力的圣物，如神圣 Chu 果及莫师法具中的圣袋、圣灯。 |
| **Cửa sổ tông / cái / chái / ngoài** | 古芒族高脚屋特有的窗户布局，其中 *tông* 窗位于连接祭祀与待客空间的正厅。 |
| **Xống** | 芒族女性长裙，裙腰处织有精致纹样（*đầu váy con hươu*）。 |
| **Phá** | 老挝族与泰族传统的织锦被面与枕套。 |
| **Bông** | 织绣图案、花纹。 |
| **Con chạng kha** | 水黾，贴着水面滑行的小虫。 |
| **Chõ / Thúng / Nia / Đụn** | 传统量具与盛器：*chõ* 约合五公斤米，*thúng* 为竹编箩筐，*nia* 为晒谷大竹匾，*đụn* 为高达三米的储粮仓。 |
| **Ang / Đép / Đọi** | *Ang*：大盆或深潭；*đép*：盛盐小竹器；*đọi*：大汤碗。 |
| **Cây chu / Cây lụi** | 古芒人心目中的宗族与权威神树（石干、铜叶、黄铜花、白锡果）。 |
| **Moong（Moong Lồ, moong mật）** | 山林猛兽；*Moong Lồ* 特指第 23–24 章中由冤血化生的巨兽。 |
| **Phường sắc bùa** | 新春或盛大仪典中边敲锣鼓边吟唱祝词的迎祥乐队。 |

## 讲述小贴士

- 遇到不确定的芒语古词时，**不要在故事中途停下来解释**；稳稳念出声韵、保持节奏，待讲完后再为孩子补充说明。
