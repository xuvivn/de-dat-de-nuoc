# Level 0 — 史诗背景与文化灵魂总览

> *“想听故事，就请坐下来；想听懂芒族大地，就请静心听完一整夜莫礼吟诵。”*
> —— 依第一章节奏的开篇吟唱

---

## 1. 整体脉络：从混沌天地到光明的芒地与国土

整部史诗共分 **6 幕 · 28 章**，面向 **9–10 岁**儿童，紧扣《生土生水》（*Đẻ đất đẻ nước*）合编本，保留芒族莫礼（*Mo lêu*）诗歌的呼吸与吟诵节奏。全书并非零散故事的拼盘，而是一段**浑然一体的生命历程**：土地诞生、雨水降临、巨木生长、村落成型、人类出现，人们随后学会建屋、取火、种稻、酿酒、驯牛、铸铜鼓、划分土地——并在故事后半段学习面对贪婪所付出的代价。

1. **第一幕 — 开天辟地与族群起源（第 1–7 章）：**
   从无天无地的虚无中，大洪水退去后露出最初的土地；大地上长出九十枝青树，生出祖先 Thu Tha 与 Thu Thiên；连结天地的巨大榕树倒下后化作一千九百一十九个芒地（村落）；朽木生出 Dạ Dần 祖母、两位 Cun Bướm 兄弟，以及最终孵化出各族与世人的神卵。幕末，人类学会分年分月，懂得顺应四时。

2. **第二幕 — 立郎建芒与创造文化（第 8–16 章）：**
   村落成型，却需要一位守护者。迎请 Dịt Dàng 与 Lang Tà Cái 均因妖鬼拦路而失败；第三次，谦逊的 Lang Cun Cần 敢于挺身立于路中，驱散妖鬼、护佑芒地。随后是一连串“学艺”之旅：向金龟学建高脚屋、向火神求火与水、上天求稻种、学做酒曲、讨来猪与鸡，并驯服水牛陪伴人类耕作。

3. **第三幕 — 成家、铸铜鼓与分地（第 17–19 章）：**
   Lang Cun Cần 因违背禁律娶亲生妹 Vạ Hai Kịp 而招致灾祸，诞生十二位 Ma Ếm 妖鬼；随后他另娶四位贤妻并生下四子。芒地众匠铸成神圣铜鼓。然而分地时，最优秀的儿子 Lang Cun Khương 仅分得如猴耳般狭小的瘠地，埋下嫉妒、诬告与幼弟 Toóng Ín 首次殒命的悲剧。

4. **第四幕 — Chu 树周期：寻树、砍树、建屋与焚屋（第 20–23 章）：**
   这是全史诗的核心。淳朴看田人 Tặm Tạch 寻获铜叶石干的 Chu 树，金莺嘱咐他切勿告知富贵王侯；他却因夸口被骗、被迫带路。大树不惧巨斧，却倒在手掌般大小的小斧之下；人力无法拖动，最终靠水獭群与 Tặm Tạch 自己的骨骼才拉回芒地。宏伟 Chu 屋落成后，被 Tặm Tạch 的两个遗孤纵火焚毁；冤血化作巨兽 Moong Lồ。

5. **第五幕 — 除猛兽与平息鬼乱（第 24–27 章）：**
   芒人合力猎杀 Moong Lồ，并将皮肉分给各民族——由此解释各族织绣技艺的由来。但凶戾沿链条蔓延：狗食怪肺发疯、鱼食疯狗发狂、乌鸦食疯鱼狂鸣。最后，被遗忘香火的亡弟 Toóng Ín 两度化作鬼敌来犯，直至在激流中被彻底击败。

6. **第六幕 — 凯旋归来 Đồng Chì Tam Quan Kẻ Chợ（第 28 章）：**
   芒地已安宁富足。终章呈现迎王回朝的三段仪典：种桑养蚕织王衣、寻巧匠造龙轿、护送君主回归 Đồng Chì。雄鸡与长老的叮嘱提醒人们：走向繁华的 Kẻ Chợ，仍要铭记生养自己的祖地。

## 2. 贯穿全篇的六条象征金线

为 9–10 岁孩子准备讲述声音时，可留意全书 28 章反复回响的六个意象：

- **土地与水：** 洪水退后生土地，大旱之后雨润大地，鬼乱之时洪水再起。“土地与水”不仅是前两章之名，更是整个生命舞台。
- **树木：** 九十枝青树 → 连天榕树 → 石干铜叶 Chu 树 → 养蚕桑树。每棵树都标志着芒地迈入新阶段；违理砍树则木不倒，失道焚木则怪兽生。
- **火种：** 火神之火熄于崖下 → 火绒取火之法 → 大火焚烧 Chu 屋十七日。火既是文明之光，也是怒火。
- **房屋：** 龟甲高脚屋 → Lang Cun Cần 之屋 → 宏伟 Chu 屋 → 焦土废墟。房屋是芒地秩序的尺度。
- **召唤与诺言：** *“无米者舂米，无鱼者捕塘”*——每次大事前皆响起这句号召；金莺的叮嘱与对水獭的承诺，决定了整个第四幕的命运。
- **贪婪的代价：** 史诗愈往后愈清晰：靠欺骗夺来的珍宝，终须以血肉偿还。

## 3. 9–10 岁儿童心理与标准讲述节奏

- **年龄特点：** 9–10 岁的孩子开始清晰辨别善恶与公允，对“不义必有果报”极为敏感；同时喜欢听数字、清单与奇特名号（一千九百一十九芒、三千七百网眼），因为这些细节让神话变得真实可触。
- **莫礼（Mo）讲述基调：**
  - 稳重、均匀，如轻轻敲锣。不必过度夸张表演，每一诗行是一口自然的呼吸，段落结束留一拍停顿。
  - 保留具象比喻：*“初夜大如茄籽，黎明大如柚果”*、*“树影初昏如杵，清晨如席”*。
  - 对话微调声线：金莺温和舒缓，Lang Cun Khương 沉稳果断，Tặm Tạch 轻声犹豫。
  - 沉重段落（Tặm Tạch 遇害、Toóng Ín 被逐、Moong Lồ 降生）**简洁带过，不渲染血腥**；悲痛来自全芒无声的哭泣。
  - 每章结尾放慢收束，留下一句余韵或下一章的引子。

## 4. 五级练习体系使用建议

1. **Level 0（背景与灵魂）：** 讲述前先读总览与分幕背景，把握文化精神、呼吸节奏与专有名词读法。
2. **Level 1（全文朗读）：** 依每章末尾的*讲述语气提示*练习出声朗读，熟悉重音与停顿。
3. **Level 2（详细提纲）：** 脱离正文，依“人物与意象—详细发展—讲述重点”串联全章。
4. **Level 3（精简提纲）：** 快速核对 28 章骨架，确保情节转折不断线。
5. **Level 4（纯视觉记忆）：** 仅凭画面与个人活语言自由讲述（当前本库画作尚待绘制，Level 4 保留绘图题材规范，亦可由讲述者上传手绘图片）。
